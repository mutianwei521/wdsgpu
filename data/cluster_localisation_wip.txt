==============================================================================
模块一：簇级（子区）漏损定位 - 相干 × 拓扑受约束聚类 + 组稀疏反演
==============================================================================
机器 <workstation>；零节点/链路/传感器编号
  T1 / T2 / T3 = 本文给三个真漏点的匿名别名（与任何网中同名元件无关）；
  簇、传感器、候选一律不带编号，只报数量、半径（m）、直径（m）与子区管长（km）。

算法（dgga/cluster.py，只新增函数）
  变量  x_j ≥ 0 = 候选 j 的漏损系数（用户制 C，q = C·p^γ）；A(S) = 签名字典，
        n = 帧数×|S| 行；观测 y = h(真值) − h(基线) + N(0,σ²)。
  相干  μ_ij = |a_iᵀa_j| / (‖a_i‖‖a_j‖)。
  拓扑  管网 Voronoi（多源 Dijkstra，边权 = 管长 m）→ 候选级相邻矩阵（无阈值参数）。
  聚类  受约束凝聚层次（complete linkage）：只合并拓扑相邻簇，
        s(g,h) = min 交叉相干，合并到 max s < τ ⇔ 簇内任意两候选 μ ≥ τ。
  反演  min_{x≥0} ½‖Ax−y‖² + λ Σ_g √|g|·‖x_g‖₂（FISTA；非负组近端
        prox(v)_g = (1 − λw_g/‖v_g⁺‖)₊·v_g⁺）。组 = 单点 ⇒ 非负 Lasso = 单点定位对照。
  选 λ  真值无关：λ 由大到小，第一个使 RSS ≤ max(σ²(n+2√(2n)), min RSS + 2σ²√(2n)) 者。
        （字典是线性化近似，实测 RSS 常达不到纯噪声地板，故用后一项兜底。）
  步骤 ① 前向算签名字典 A（冻结状态灵敏度）→ ② 管网 Voronoi 得候选相邻 →
        ③ 受约束层次聚类得 labels(τ) → ④ 沿 λ 由大到小暖启动跑 FISTA 路径 →
        ⑤ 偏差原则选 λ* → ⑥ 按 ‖x_g‖₂ 给簇排名，报命中与该簇半径/直径/子区管长。
  复杂度 Voronoi O(L log N)；候选两两管距 O(NC·L log N)；聚类 O(NC³)（堆可降 O(NC² log NC)）；
        FISTA 每步两次矩阵-向量乘 O(n·NC)，n = 帧数×|S|；λ 路径 = LAM_GRID × 迭代数。
  实测（<workstation>，单核 numpy；N=542 节点、L=554 管、NC=49 候选、n=1000 观测）：
        Voronoi+相邻 0.00s；候选两两管距 0.06s；相干矩阵 0.002s；
        聚类(τ=0.99→13 簇) 0.002s；单 λ FISTA 0.30s/3000 步；整条 λ 路径(14 点，暖启动) 2.82s。
