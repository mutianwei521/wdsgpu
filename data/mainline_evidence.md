## 1. 正确性（本机前台，`scripts/ltown_mainline/correct_ltown.py`）

| 项 | 实测 | 判定 |
|---|---|---|
| epanet 通路 vs 双精度 DLL（帧 0） | 状态 909/909 全同；iters 17/17；**DLL 用户单位出口（米/CMH）head 785/785、flow 909/909 逐位相同**；内部 ft 口径 max\|dH\|=2.842e-14 ft（≤1 ULP，266/782 非零）、max\|dQ\|=1.110e-16 cfs | **位级 PASS** |
| dense(SM) vs DLL 同帧 | max\|dH\|=1.366e-06 ft，max\|dQ\|=4.184e-07 cfs，iters=17，状态全同 | 量级口径（κ≈1.6e11 × 线代次序差） |
| CSR vs 稠密装配（linear_solver 同 dense） | 逐迭代 A 17 轮逐位相同（max\|dA\|==0.0）；终态 head/flow/emitter/status/iters 逐位相同 | **逐位 PASS** |
| 三方迭代数 | DLL=17，epanet=17，dense(SM)=17 | 相等 |
| 收敛帧 κ₂(A)（ACTIVE PRV=3/3 在场） | 名义帧 **1.644e+11**（diag_ratio 代理 3.02e+08）；DLL 帧 1.641e+11 | - |
| 参考解收紧（能量失衡 ≤1e-8 ft） | base（INP ACCURACY=0.01 停机）7.94e-05 / 7.79e-05 ft → **K_extra=10** 后 2.18e-12 / 3.67e-13 ft，met=True | PASS |

读法三条：

- **“逐位 0”在 SI 网上的正确口径**：L-TOWN 是 CMH/米网，DLL 的 API 出口把内部
  ft/cfs 乘 Ucf 变成米/CMH，参考端再除回内部单位 - 这一往返本身有 ≤1 ULP。
  在 DLL 的用户单位出口上逐位比较（×0.3048 / ×101.94 后逐元素 `==`）：
  **head 785/785、flow 909/909 全部逐位相同**。残差全部归因于参考端单位往返，
  不在求解器。
- dense 与 DLL 的 1.4e-06 ft 是 κ≈1.6e11 放大线代次序差的预期量级
  （ACTIVE PRV 的 CBIG=1e8 罚函数对角是 κ 的来源），不设位级门槛。
- 拿 L-TOWN 当参考解时必须过 `dgga.reference.tight_reference`：INP 自带
  ACCURACY=0.01 的停机解距收紧解 1.7e-04 ft；追加 K=10 步冻结状态 Newton
  即到 1e-12/1e-13 ft（工单的“K≥20”是 NW_Model 的口径，L-TOWN 用不满，如实报）。

**形态说明（这一节最重要的一句）**：L-TOWN 含 3 个 PRV，前向必须走批量状态机
（`solve(status_machine=True)`，K=17）；`solve_unrolled` 对 PRV **维持 raise**，

f+b = **实际训练形态**：GPU 批量前向（no_grad）拿逐场景收敛状态 S* →
ImplicitGGASolve 按唯一状态分组、冻结 S* 做**CPU** 隐式伴随（epanet 求解器 +
scipy splu，逐场景串行）。伴随段与线性求解器无关，两列共享，表里分列给出。

### 3.4 诚实边界（必须随表引用）

1. f+b 的 1.01~1.07x 不是稀疏没用，是**伴随段在 CPU 串行**（solve_polished +
   逐场景 splu）。把 ImplicitGGASolve 的 forward/backward 批量化或搬上 GPU
   （复用 cudss 分解解 J^T λ=g）是明确的下一步，本轮未做。
   **【v2 已消项】**：`adjoint="gpu"`（d6a8f90）已做，实测见 §5 - 这一条
   不再是未做项。
2. impl 段跨节点差 ~48%（322 vs 487 ms/场景） - 纯 CPU 主频/内存差，引用时
   给区间，不给单值。
3. 3.2 的 B=1024 行 A/Badj 无数：分解脚本要在求解器之外另持 [B,Nj,Nj] 的
   梯度张量，先于求解器 OOM；不是 3.3 表的矛盾（那边纯前向 B=1024 能跑）。
4. 本表场景 = 名义帧 ±15% 需水、水库 ±1 ft、tank 中位（P4/P5 同分布），
   整批收敛到同一状态构型（状态组=1）；逼阀极端批的调度/终态一致性另见
   prv 轮 M4/M9（data/prv_port_wip.txt），不混入本表。
